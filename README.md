# Hi, I'm Matus Labaj

I'm a solo founder in Prague building **[Coincruze](https://coincruze.com)**, an AI portfolio manager that records a plain-English reason for every decision it makes, including a decision to do nothing. I study Applied Informatics at the University of Economics in Prague and have been investing my own money for three years.

> Coincruze is pre-launch. It runs in paper trading with test accounts only. It has no customers and no real-money trading, and it is not a registered investment adviser. Nothing here is investment advice.

## What I'm working on now

- **Coincruze:** four services (a Rails web app plus Python services for asset scoring, news sentiment and trading) that run a daily decision cycle and place orders at Interactive Brokers, with rules the AI cannot override. Overview and architecture: **[coincruze-overview](https://github.com/Saborou9/coincruze-overview)**. The source code is private.
